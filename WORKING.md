# Working on Monster Plant

These are Jackie's instructions for every work session in this repo.

1. **Read first:** [README.md](README.md), [RULES.md](RULES.md) and [DECISIONS.md](DECISIONS.md), before changing anything.
2. **One thing per request.** Change only what was asked. Note anything else you spot as a follow-up instead of fixing it.
3. **Run `python tests/smoke_test.py` before and after every change.** If it fails, fix what broke before you stop.
4. **Show Jackie screenshots of what changed.**
5. **Log decisions:** add an entry at the top of [DECISIONS.md](DECISIONS.md) for anything Jackie decides, with the reason.
6. **Commit and push to `main` only when the tests pass.**
